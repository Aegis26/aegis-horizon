## Task 2: Locate the Email Sending Function

Find the email helper:
- Should be in `artifacts/api-server/src/lib/email.ts`
- Look for a function like `sendInvitationEmail()` or create one

It should look like:
```typescript
import { resend } from '@/lib/resend' // or similar

export async function sendInvitationEmail(
  email: string,
  orgName: string,
  invitationLink: string
) {
  return await resend.emails.send({
    from: "Aegis Horizon <noreply@aegishz.com>",
    to: email,
    subject: `You're invited to join ${orgName}`,
    html: `
      <h1>Welcome to Aegis Horizon</h1>
      <p>You've been invited to join <strong>${orgName}</strong>.</p>
      <p><a href="${invitationLink}">Click here to accept</a></p>
      <p>This link expires in 7 days.</p>
    `,
  })
}
```

If it doesn't exist, **create it** in `artifacts/api-server/src/lib/email.ts`

## Task 3: Update the Invitation Endpoint

In `artifacts/api-server/src/routes/orgs.ts`, find where membership is created.

**BEFORE (current code - missing email):**

**AFTER (add email sending):**
```typescript
import { sendInvitationEmail } from '@/lib/email'

app.post('/orgs/:orgId/members', async (req, res) => {
  const { email, role } = req.body
  
  // Get org name for email
  const org = await db.query.organizations.findFirst({
    where: eq(organizations.id, orgId),
  })
  
  // Create membership with invitation token
  const invitationToken = crypto.randomBytes(32).toString('hex')
  const membership = await db.insert(orgUsers).values({
    org_id: orgId,
    email,
    role,
    status: 'pending',
    invitation_token: invitationToken,
    invitation_sent_at: new Date(),
    // ... other fields
  })
  
  // Send invitation email
  try {
    const invitationLink = `${process.env.NEXT_PUBLIC_APP_URL}/invite/${invitationToken}`
    
    await sendInvitationEmail(
      email,
      org.name,
      invitationLink
    )
  } catch (error) {
    console.error('Failed to send invitation email:', error)
    // Still return success - membership was created
    // Email can be resent from UI if needed
  }
  
  res.json({ 
    success: true,
    message: 'Invitation sent'
  })
})
```
