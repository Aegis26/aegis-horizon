# Add Sign Out Button to Application

**Goal:** Add a visible Sign Out button so users can logout from the app.

**Current Problem:**
- Users can't sign out
- No logout button anywhere in the UI
- Users are stuck logged in

**Expected Behavior:**
- Sign Out button visible in Settings page (or user menu)
- Click Sign Out → Logs out from Clerk
- Redirects to login/home page
- Clears session

## Task 3: Add Sign Out Button

Add a button that calls `signOut()` from Clerk.

**Template:**

```typescript
// In the Settings page or user menu component
import { useClerk } from '@clerk/nextjs'
import { useRouter } from 'next/router'

export default function SettingsPage() {
  const { signOut } = useClerk()
  const router = useRouter()

  const handleSignOut = async () => {
    // Sign out from Clerk
    await signOut()
    
    // Redirect to home/login
    router.push('/')
  }

  return (
    <div>
      {/* ... existing settings content ... */}

      {/* Sign Out Button - add at bottom of settings */}
      <div className="mt-8 pt-8 border-t border-slate-700">
        <button
          onClick={handleSignOut}
          className="px-6 py-2 bg-red-500/10 hover:bg-red-500/20 text-red-400 border border-red-500 rounded transition"
        >
          Sign Out
        </button>
      </div>
    </div>
  )
}
```
