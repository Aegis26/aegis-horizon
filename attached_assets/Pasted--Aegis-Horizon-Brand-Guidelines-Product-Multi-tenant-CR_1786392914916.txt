# Aegis Horizon — Brand Guidelines

**Product:** Multi-tenant CRM SaaS  
**Brand:** Aegis Horizon  
**Tagline:** *See Beyond the Horizon*  
**Logo:** Layered geometric star with horizon line, electric blue accent on deep navy background  
**Target Audience:** Enterprise sales teams, SMBs, K-12 IT procurement, service organizations

---

## 1. Brand Overview

**Brand Promise:** Aegis Horizon brings clarity to customer relationships. Every interaction, every opportunity, every insight—visible at a glance. The horizon line represents forward vision: forecasting, expansion, growth beyond what's currently visible.

**Brand Personality:**
- **Authoritative** — You trust this for mission-critical work
- **Clear** — No clutter, no confusion, designed for decision-makers
- **Forward-thinking** — AI, predictions, what's next
- **Precise** — Data-driven, not approximate
- **Professional** — Enterprise-grade, no playfulness or gimmicks

**Why this matters:** The design system enforces clarity and confidence at every level.

## 2. Logo & Mark

### Logo Usage

**Primary Logo** (Use this in most contexts)
- Horizontal layout: Shield + star icon + "AEGIS HORIZON" text
- Minimum size: 120px width
- Always maintain clear space around logo (1/4 of logo width on all sides)
- Never rotate, skew, or distort the mark

**Icon Mark Only** (For tight spaces, app icons, favicon)
- Star shield alone
- Minimum 32px (app icon size)
- Use on any background where contrast is sufficient

**Logo Lockup Files Needed:**
- `aegis-horizon-logo-full.svg` (full logo)
- `aegis-horizon-icon.svg` (star only)
- `aegis-horizon-wordmark.svg` (text only, rarely used)
- All as SVG and 2x PNG for web

### Don'ts
- Never change colors (blue is non-negotiable)
- Never add drop shadows or effects not in original
- Never place on backgrounds where blue doesn't have 4.5:1 contrast
- Never use in rotated/skewed forms
- Never outline the logo in a different color

### Color Combinations (Accessible)

**Primary action (on dark):**
- Electric Blue text/button on Deep Navy background ✓ (4.8:1 contrast)
- Off-white text on Electric Blue background ✓ (6.2:1 contrast)

**Secondary action (on dark):**
- Accent Blue text on Deep Navy ✓ (3.1:1 contrast, acceptable for UI)
- Off-white text on Accent Blue ✓ (7.1:1 contrast)

**Status indicators:**
- Green (#10B981) for success ✓ (all backgrounds)
- Warning (#F59E0B) for attention ✓ (pair with dark text)
- Red (#EF4444) for error ✓ (all backgrounds)

## 4. Typography

### Font Stack

**Headings & Display Text**
- Font: **Archivo** (Google Fonts)
- Weights: 600, 700, 800
- Letter spacing: -0.5px (tight, technical feel)
- Used for: H1, H2, H3, nav items, strong labels

**Body & UI Text**
- Font: **Public Sans** (Google Fonts)
- Weights: 400 (regular), 500 (medium), 600 (semi-bold)
- Letter spacing: 0px (neutral)
- Used for: paragraphs, form labels, descriptions

**Monospace (Dates, Times, Data)**
- Font: **Roboto Mono** (Google Fonts)
- Weight: 400
- Letter spacing: 0px
- Used for: timestamps, numbers, code, data tables
- Why: Numbers in a mono font align vertically, critical for scanning data

### Type Scale

| Usage | Font | Size | Line Height | Weight | Example |
|-------|------|------|-------------|--------|---------|
| **Page Title (H1)** | Archivo | 32px | 1.2 | 700 | "Opportunities" |
| **Section Header (H2)** | Archivo | 24px | 1.3 | 700 | "Pipeline This Quarter" |
| **Subsection (H3)** | Archivo | 18px | 1.3 | 600 | "Prospecting" |
| **Label / Small Title** | Archivo | 14px | 1.5 | 600 | Form labels, card titles |
| **Body Text** | Public Sans | 14px | 1.6 | 400 | Descriptions, paragraphs |
| **Small Text** | Public Sans | 12px | 1.5 | 400 | Helpers, captions, metadata |
| **Data / Timestamp** | Roboto Mono | 14px | 1.5 | 400 | "2025-08-10 14:23" |

### Tailwind Typography Config

```javascript
// tailwind.config.js extension
export default {
  theme: {
    extend: {
      fontFamily: {
        display: ['Archivo', 'sans-serif'],
        sans: ['Public Sans', 'sans-serif'],
        mono: ['Roboto Mono', 'monospace'],
      },
      fontSize: {
        'h1': ['32px', { lineHeight: '1.2', fontWeight: '700' }],
        'h2': ['24px', { lineHeight: '1.3', fontWeight: '700' }],
        'h3': ['18px', { lineHeight: '1.3', fontWeight: '600' }],
        'label': ['14px', { lineHeight: '1.5', fontWeight: '600' }],
        'body': ['14px', { lineHeight: '1.6', fontWeight: '400' }],
        'small': ['12px', { lineHeight: '1.5', fontWeight: '400' }],
        'data': ['14px', { lineHeight: '1.5', fontWeight: '400', fontFamily: 'Roboto Mono' }],
      },
      letterSpacing: {
        tight: '-0.5px',
        normal: '0px',
      },
    },
  },
};
```

### Font Import

Add to `globals.css`:

```css

.data { @apply font-mono text-data; }
```

### Spacing System

Use multiples of 4px (Tailwind default):

```
4px   (xs)   — tight, icon spacing
8px   (sm)   — small padding, gaps
12px  (md)   — standard padding, list gaps
16px  (lg)   — card padding, section gaps
20px  (xl)   — large spacing
24px  (2xl)  — section breaks
32px  (3xl)  — major section breaks
```

## 6. Imagery & Icons

### Icon Style

**Use:** Heroicons (Outline style) or Feather Icons  
**Size:** Typically 20px (UI), 24px (buttons), 32px (hero sections)  
**Color:** Primary Electric Blue (#00B4D8) by default  
**Stroke width:** 2px (consistent with outline style)

**Icon Usage Rules:**
- Every icon-only button must have an `aria-label`
- Never color-code icons alone (add text or badge if status indication needed)
- Icons should have 44px minimum tap target on mobile

### Photography & Imagery

**Style:** Modern, minimalist, technical but human  
**Tone:** Forward-looking, professional, inclusive  
**Avoid:** Clichés (handshake photos, fake diversity), bright colors that clash with blue palette

**If using background images:**
- Darken with overlay to maintain text readability
- Overlay opacity: 60–70% (so images are visible but text is legible)

### Illustrations

When creating custom illustrations:
- Use accent blue and electric blue as primary colors
- Geometric, technical style to match logo
- Avoid realistic or overly playful rendering

## 7. Layout & Spacing

### Page Structure

**Desktop (1200px+)**
- Left sidebar (240–280px) with navigation
- Main content area (responsive, fills remaining space)
- Max content width: 1400px

**Tablet (768px–1199px)**
- Left sidebar collapses to icon-only navigation
- Hamburger menu overlay on top

**Mobile (< 768px)**
- Bottom navigation bar (safe area bottom)
- Full-width main content
- No sidebar

### Grid & Alignment

- Use CSS Grid for layouts, Flexbox for components
- 12-column grid for responsive design
- Gutters: 20px (desktop), 16px (tablet), 12px (mobile)

## 8. Voice & Tone

### Brand Voice

**Traits:**
- Confident but not arrogant
- Clear over clever
- Action-oriented
- Data-driven, not emotional

**Examples:**

| Context | Voice | ❌ Don't |
|---------|-------|---------|
| Success message | "Deal closed. Well done." | "Yay! You crushed it! 🎉" |
| Error message | "Email already in use. Try another." | "That email is borked, bro." |
| Empty state | "No opportunities yet. Create your first." | "Looks like you forgot to add deals!" |
| Call-to-action | "Start forecasting" | "Let's go forecast!" |
| Help text | "Dates are in your local timezone." | "Just so you know, we're smart about timezones." |

### Tone Rules

1. **Sentence case** — "Schedule your calls" not "SCHEDULE YOUR CALLS"
2. **Active voice** — "You have 3 overdue tasks" not "3 tasks are overdue to you"
3. **Specific** — "Add your first account" not "Get started"
4. **No jargon unless the user speaks it** — Sales folks say "pipeline", don't assume all users do
5. **One idea per sentence** — Clarity over brevity
6. **No emoji in UI** — Reserve for marketing/social

## 9. How Replit Agent Should Use This Guide

When building Aegis Horizon components, the Agent should:

1. **Import brand tokens at the top of every component file:**
   ```typescript
   // Use CSS custom properties defined in globals.css
   const primaryColor = 'var(--color-primary)'; // #00B4D8
   const bgDark = 'var(--color-bg-dark)'; // #0A0E27
   ```

2. **Apply Tailwind classes consistently:**
   ```jsx
   <button className="bg-primary text-bg-dark font-display text-label rounded-md px-5 py-2.5 hover:shadow-lg hover:bg-opacity-90">
     Create Account
   </button>
   ```

3. **Use semantic spacing:**
   ```jsx
   <div className="space-y-6 p-6"> {/* 24px gaps, 24px padding */}
   ```

4. **Ensure accessibility:**
   ```jsx
   <button aria-label="Close dialog">
     <Icon name="x" size={20} />
   </button>
   ```

5. **Reference voice & tone for all text:**
   - Button copy should be clear actions: "Create opportunity" not "New opportunity"
   - Error messages should be specific: "Email already registered" not "Error"
   - Help text should educate: "Closed dates lock the record from edits" not "Lock this"

6. **Card and component structure should match the template patterns** provided above.

## 10. Dark Mode (Only Mode)

Aegis Horizon is **dark-mode only**. This is intentional:

- **Brand alignment:** Deep navy + electric blue is your identity
- **User comfort:** Sales teams often work in dark offices
- **Performance:** Dark pixels use less power on OLED screens
- **No light mode toggle** — it confuses users and adds maintenance burden

If a customer requests light mode, that's a Phase 6+ feature, and it would require a complete color remap.

## 11. Do's and Don'ts

### ✅ Do

- Use Electric Blue (#00B4D8) as your primary action color
- Keep text on dark backgrounds high-contrast (4.5:1 minimum)
- Use Archivo for headings and labels (bold, geometric)
- Use Roboto Mono for all dates, times, and numeric data
- Stack cards with subtle borders and shadows
- Test all color combinations for accessibility (WCAG AA minimum)
- Use focus rings on all interactive elements
- Maintain consistent spacing (multiples of 4px)

### ❌ Don't

- Use neon or extremely bright accent colors
- Place Electric Blue text on very light backgrounds (loses the brand feel)
- Mix fonts — only Archivo, Public Sans, and Roboto Mono
- Add drop shadows, gradients, or effects not specified here
- Use rounded corners > 8px (breaks the geometric theme)
- Include decorative graphics that compete with data
- Assume users can see without color (always pair color with pattern/text)
- Change the logo colors, proportions, or orientation

## 13. Accessibility Checklist

Before shipping any screen:

- [ ] Color contrast is ≥ 4.5:1 for body text, ≥ 3:1 for large text
- [ ] All interactive elements are keyboard accessible
- [ ] Focus rings are visible (not hidden)
- [ ] Form labels are properly associated with inputs (`<label htmlFor="...">`)
- [ ] Icon-only buttons have `aria-label`
- [ ] Images have alt text (or `alt=""` if decorative)
- [ ] No color alone conveys meaning (pair with text or icon)
- [ ] Tap targets are ≥ 44px on mobile
- [ ] No flashing or rapid animations that could trigger seizures
