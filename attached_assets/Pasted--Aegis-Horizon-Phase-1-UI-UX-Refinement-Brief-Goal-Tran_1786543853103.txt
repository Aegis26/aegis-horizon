# Aegis Horizon — Phase 1 UI/UX Refinement Brief

**Goal:** Transform Phase 1 from default shadcn into enterprise-grade, where every pixel is intentional. This is a polish pass executed by Replit Agent before shipping Phase 1 to beta users.

**Standard:** Every component must feel like it was designed by a 50-person design team. No default Tailwind grays. No unrefined shadows. No clunky interactions.

---

## 1. Global Refinements

### Shadows (Shadow Hierarchy)

CSS custom properties to replace all default shadows:

```css
/* shadows.css */
:root {
  /* Subtle elevation (cards, inputs on hover) */
  --shadow-xs: 0 1px 2px 0 rgba(0, 0, 0, 0.05);
  --shadow-sm: 0 1px 3px 0 rgba(0, 180, 216, 0.08), 0 1px 2px 0 rgba(0, 0, 0, 0.04);
  
  /* Standard elevation (cards, modals) */
  --shadow-md: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 180, 216, 0.06);
  --shadow-lg: 0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 180, 216, 0.08);
  
  /* Pronounced elevation (floating nav, modals on top) */
  --shadow-xl: 0 20px 25px -5px rgba(0, 0, 0, 0.15), 0 10px 10px -5px rgba(0, 180, 216, 0.1);
  
  /* Glow effect (hover on primary buttons, focus states) */
  --glow-primary: 0 0 16px rgba(0, 180, 216, 0.3);
  --glow-primary-hover: 0 0 24px rgba(0, 180, 216, 0.4);
  
  /* Inset shadow (pressed states, active elements) */
  --shadow-inset: inset 0 2px 4px 0 rgba(0, 0, 0, 0.2);
}

/* Apply to default Tailwind shadow classes */
.shadow-xs { box-shadow: var(--shadow-xs); }
.shadow-sm { box-shadow: var(--shadow-sm); }
.shadow-md { box-shadow: var(--shadow-md); }
.shadow-lg { box-shadow: var(--shadow-lg); }
.shadow-xl { box-shadow: var(--shadow-xl); }
.shadow-glow { box-shadow: var(--glow-primary); }
```

### Transitions (Smooth, not jarring)

```css
/* transitions.css */
:root {
  --transition-fast: all 0.15s cubic-bezier(0.4, 0, 0.2, 1);
  --transition-base: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
  --transition-slow: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

/* All interactive elements use these */
button, a, input, select, textarea {
  transition: var(--transition-base);
}

/* Slower for modals/overlays */
.modal, .dropdown {
  transition: var(--transition-slow);
}
```

### Opacity & Hover States

```css
/* opacity.css */
:root {
  --opacity-hover: 0.08;
  --opacity-active: 0.12;
  --opacity-disabled: 0.5;
}

/* Hover overlay for non-button interactive elements */
.interactive:hover {
  background-color: rgba(0, 180, 216, var(--opacity-hover));
}

.interactive:active {
  background-color: rgba(0, 180, 216, var(--opacity-active));
}

.interactive:disabled {
  opacity: var(--opacity-disabled);
  cursor: not-allowed;
}
```

## 5. Interaction Refinements

### Focus Management

All interactive elements must have visible focus rings:

```css
*:focus-visible {
  outline: 2px solid #00B4D8;
  outline-offset: 2px;
  border-radius: 4px;
}

/* Except buttons which have custom focus styles */
button:focus-visible,
a:focus-visible {
  outline: 2px solid #00B4D8;
  outline-offset: 2px;
}
```

### Disabled States

```css
[disabled],
[aria-disabled="true"] {
  opacity: 0.5;
  cursor: not-allowed;
  pointer-events: none;
}
```

### Loading States on Buttons

```jsx
<button disabled className="btn-primary relative">
  {loading ? (
    <>
      <span className="opacity-0">Save</span>
      <div className="absolute inset-0 flex items-center justify-center">
        <div className="spinner" />
      </div>
    </>
  ) : (
    'Save'
  )}
</button>
```

### Link Styling

```css
a {
  color: #00B4D8;
  text-decoration: none;
  transition: all 0.15s ease;
  border-bottom: 1px solid rgba(0, 180, 216, 0.3);
  padding-bottom: 2px;
}

a:hover {
  border-color: #00B4D8;
  text-decoration: underline;
}

a:active {
  color: #0066CC;
}

a:visited {
  color: #0066CC;
}
```
