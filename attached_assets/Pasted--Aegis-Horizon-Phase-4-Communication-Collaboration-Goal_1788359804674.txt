# Aegis Horizon — Phase 4: Communication & Collaboration

**Goal:** All customer communication flows through Horizon. Every email, call, calendar event, and internal note is unified on the timeline. Teams collaborate in-app with real-time mentions and Slack notifications.

**Deliverables:** Gmail + Outlook email sync and logging, Twilio call recording + transcription, Google Calendar + Outlook sync, Internal notes with @-mentions, Slack integration for notifications, Conversation intelligence (summaries, sentiment, keywords).

**Acceptance Criteria:**
1. Gmail synced; emails to/from contacts auto-log to account timeline (not manual copy-paste).
2. Call via Twilio gets recorded, transcribed, and appears on timeline with sentiment analysis.
3. Google Calendar events synced; meeting attendees matched to contacts.
4. Internal note with @-mention notifies rep in Slack.
5. Email thread summary: "Customer expressed 2 objections, leaning toward yes" auto-generated.
6. All communications (emails, calls, meetings) visible in unified timeline by date.

---

## Stack

| Component | Choice | Why |
|---|---|---|
| Email Sync | Gmail API + Outlook Graph API | Industry standard, covers 95% of users |
| Call Recording | Twilio + Cloudflare R2 | You know Twilio; recordings stored in R2 |
| Transcription | AssemblyAI (via Resend email template triggers) | Fast, accurate, supports sentiment |
| Calendar Sync | Google Calendar API + MS Graph | Native to Gmail and Outlook |
| Slack Integration | Slack Bolt SDK | Real-time mentions, instant notifications |
| Sentiment Analysis | Claude API (Sonnet) | You're already using Claude; no new vendor |
| Email Parsing | Parsemail (open-source) | Extract sender, recipients, reply chains |

## Core API Routes

### Email Sync

**Setup & OAuth**
- `GET /api/auth/email/gmail/oauth` — OAuth flow, store encrypted tokens
- `GET /api/auth/email/outlook/oauth` — Outlook OAuth flow
- `GET /api/email-sync/accounts` — List synced email accounts for user
- `DELETE /api/email-sync/accounts/:id` — Disconnect email account

**Email Retrieval**
- `GET /api/email-threads` — List all synced email threads for account (paginated)
- `GET /api/email-threads/:threadId` — Full thread with all messages
- `POST /api/email-sync/force-sync` — Force immediate sync (useful for testing)

**Send Email**
- `POST /api/emails/send` — Send email from CRM (using Resend, not Gmail API)
  ```typescript
  {
    to: "customer@example.com",
    subject: "Quote - Aegis Horizon Setup",
    body: "...",
    accountId: "...", // Links email to account
    attachments: [{filename, url}]
  }
  ```

**Setup**
- `GET /api/integrations/slack/oauth` — OAuth flow for Slack workspace

**Notifications**
- Internal note with @-mention → Slack DM

## Critical Implementation Details

### Email Token Encryption

Tokens must be encrypted at rest:

```typescript
import crypto from 'crypto';

const encryptToken = (token: string) => {
  const cipher = crypto.createCipher('aes-256-cbc', process.env.ENCRYPTION_KEY!);
  let encrypted = cipher.update(token);
  encrypted += cipher.final();
  return encrypted.toString('hex');
};

const decryptToken = (encrypted: string) => {
  const decipher = crypto.createDecipher('aes-256-cbc', process.env.ENCRYPTION_KEY!);
  let decrypted = decipher.update(encrypted, 'hex');
  decrypted += decipher.final();
  return decrypted.toString();
};
```

### Rate Limiting on Sync

Gmail/Outlook APIs are rate-limited. Implement backoff:

```typescript
async function syncWithBackoff(provider: 'gmail' | 'outlook') {
  const maxRetries = 3;
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await performSync(provider);
    } catch (error) {
      if (error.status === 429) {
        await sleep(Math.pow(2, i) * 1000); // Exponential backoff
      } else {
        throw error;
      }
    }
  }
}
```
