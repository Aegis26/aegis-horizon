# Aegis Horizon — Phase 5: AI, Automation & Intelligence

**Goal:** AI assists users and automates repetitive work. Copilot drafts emails, predicts outcomes, runs workflows, and agents handle autonomous tasks. Every rep feels like they have a personal AI assistant.

**Deliverables:** AI Copilot (summaries, drafts, recommendations), Predictive models (churn risk, conversion likelihood, close probability), No-code workflow automation (visual builder), AI Agents (lead qualification, follow-up sequences), AI voice assistant (natural language commands).

**Acceptance Criteria:**
1. Rep clicks "Summarize" on account → 2-sentence summary + next best action in 2 seconds.
2. Churn model flags accounts at risk; alert goes to account owner.
3. Workflow: "If opp in Proposal > 14 days, create task 'Follow up'" — executes automatically.
4. Agent: New lead arrives → Auto-qualified, opportunity created, outreach drafted, follow-up scheduled.
5. Rep speaks: "Show my largest open deal and schedule a call for tomorrow at 2pm" → Executed.

## Stack

| Component | Choice | Why |
|---|---|---|
| AI LLM | Claude (Anthropic) | You're already using it; consistent API |
| Embeddings | Anthropic Embeddings | For semantic search in account data |
| Predictive Models | Claude + simple heuristics | Start rule-based, upgrade to ML later |
| Workflow Engine | Custom event-driven system | Lightweight, no external vendor |
| Voice Interface | Twilio Voice + Claude | Natural language command parsing |
| Scheduling | node-cron + Bull queue | Background job processing |
| Vector DB | Postgres (pgvector) | Already using Postgres; no new infra |
| API Rate Limiting | Redis + Token Bucket | Prevent Claude API abuse |

## Core API Routes

### AI Copilot

**Summaries & Analysis**
- `POST /api/ai/copilot/summarize` — Summarize account/opportunity/email
  ```typescript
  {
    entityType: 'account' | 'opportunity' | 'email_thread',
    entityId: "...",
    style: 'short' | 'long' // 2 sentences vs full paragraph
  }
  ```
- `POST /api/ai/copilot/next-action` — Recommend next action on account
- `POST /api/ai/copilot/draft-email` — Draft email response
  ```typescript
  {
    accountId: "...",
    context: "...", // Previous email or situation
    tone: 'professional' | 'casual'
  }
  ```

### Predictions

**Risk & Conversion**
- `GET /api/predictions/churn` — List accounts at churn risk
- `GET /api/predictions/churn/:accountId` — Detailed churn risk for account
- `GET /api/predictions/conversion/:leadId` — Lead conversion probability
- `GET /api/predictions/close/:opportunityId` — Deal close probability

### Workflow Automation

**Build & Manage Workflows**
- `POST /api/workflows` — Create workflow
- `GET /api/workflows` — List workflows
- `PATCH /api/workflows/:id` — Edit workflow
- `DELETE /api/workflows/:id` — Delete workflow
- `POST /api/workflows/:id/test` — Run in dry-run mode (no actual execution)
- `POST /api/workflows/:id/toggle` — Enable/disable workflow
- `GET /api/workflow-executions` — List all executions (audit log)

### AI Agents

**Agent Management**
- `POST /api/agents` — Create agent (lead qualifier, renewal monitor, etc.)
- `GET /api/agents` — List agents
- `POST /api/agents/:id/run` — Manually trigger agent
- `GET /api/agent-executions` — Agent execution history

### Voice Commands

**Voice Interface**
- `POST /api/voice/process` — Process voice command
  ```typescript
  {
    audioUrl: "...", // Or audioBase64
    context: {accountId, opportunityId} // Optional context
  }
  ```
- `GET /api/voice/commands` — History of voice commands

### Churn Risk Alert

```typescript
// components/ChurnRiskAlert.tsx
export function ChurnRiskAlert({ account }: { account: Account }) {
  const { data: churnRisk } = useQuery(
    ['churn-risk', account.id],
    () => fetch(`/api/predictions/churn/${account.id}`).then(r => r.json())
  );

  if (!churnRisk || churnRisk.riskLevel === 'low') return null;

  return (
    <div className={`alert alert-${churnRisk.riskLevel === 'critical' ? 'error' : 'warning'}`}>
      <div className="flex items-start gap-4">
        <span className="text-xl">⚠️</span>
        <div className="flex-1">
          <h4 className="font-display text-label mb-1">Churn Risk</h4>
          <p className="text-body text-text-light mb-3">
            {churnRisk.riskLevel === 'critical'
              ? 'This account is at high risk of churning within 30 days.'
              : 'This account shows signs of disengagement.'}
          </p>
          <p className="text-small text-text-light text-opacity-70 mb-3">
            Key factors: {churnRisk.riskFactors.map(f => f.factor).join(', ')}
          </p>
          <button className="btn-secondary btn-sm">
            {churnRisk.recommendedAction}
          </button>
        </div>
      </div>
    </div>
  );
}
```
