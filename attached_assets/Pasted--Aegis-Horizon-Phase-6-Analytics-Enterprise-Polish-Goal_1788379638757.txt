# Aegis Horizon — Phase 6: Analytics, Enterprise & Polish

**Goal:** Ship a complete, enterprise-grade CRM. Dashboards show what matters. Documents are managed and signed. Access is secure (SSO, MFA, IP allowlist). Mobile works offline. API lets customers integrate anything. Industry templates make setup instant.

**Deliverables:** Role-based dashboards (sales, revenue, forecasting), custom reporting (drag-and-drop builder, scheduled delivery), mobile PWA (full offline sync), document management (versioning, e-signature), open API (webhooks, full parity with UI), security hardening (SSO/SAML, MFA, IP allowlist, audit logs), industry modules (K-12, Construction, Healthcare).

**Acceptance Criteria:**
1. Sales rep sees revenue forecast for next 90 days (by week/month) based on opportunity close probability.
2. Manager exports custom report "All opportunities > $100k not touched in 7+ days" to PDF.
3. Rep uses mobile app offline, creates 3 leads, syncs when back online.
4. Finance uploads contract, marks key fields, e-signature requested, signed, versioned.
5. Partner integrates via API: POST /api/orgs/:orgId/leads/batch to create 100 leads at once.
6. Admin enables SSO; user logs in via company Okta; MFA required.
7. K-12 school admin uses pre-built K-12 template: automatic student pipeline stages, teacher role mapping.

---

## Stack

| Component | Choice | Why |
|---|---|---|
| Dashboard | React + Recharts | Real-time updates, existing dependencies |
| Custom Reporting | React Query Builder + Playwright | Visual drag-and-drop, scheduled exports |
| Mobile PWA | PWA (Vite + Service Worker) | No App Store friction, works offline |
| Offline Sync | IndexedDB + WatermelonDB | Lightweight local DB, conflict resolution |
| Document Storage | Cloudflare R2 + versioning | You already use R2; cheap + fast |
| E-Signature | EasyESign API or DocuSign Lite | Simple integration, audit trail |
| Open API | Express + generated OpenAPI | Extend existing API, no new vendor |
| Authentication | NextAuth.js + OAuth providers | SSO/SAML support, MFA via TOTP |
| Audit Logging | Existing activity table + new audit_events | Central audit trail for compliance |
| Industry Templates | Org-scoped seed data + UX flows | No separate products, just templates |

## Core API Routes

### Dashboards & Widgets

**CRUD**
- `GET /api/orgs/:orgId/dashboards` — List dashboards
- `POST /api/orgs/:orgId/dashboards` — Create dashboard
- `PATCH /api/orgs/:orgId/dashboards/:id` — Update layout/config
- `DELETE /api/orgs/:orgId/dashboards/:id` — Delete
- `GET /api/orgs/:orgId/dashboards/:id/data` — Get rendered dashboard data (with caching)

**Widget Data**
- `POST /api/orgs/:orgId/dashboards/:id/widgets` — Add widget
- `PATCH /api/orgs/:orgId/dashboards/:id/widgets/:widgetId` — Update widget config
- `DELETE /api/orgs/:orgId/dashboards/:id/widgets/:widgetId` — Remove widget

### Custom Reporting

**Reports**
- `GET /api/orgs/:orgId/reports` — List custom reports
- `POST /api/orgs/:orgId/reports` — Create report
- `PATCH /api/orgs/:orgId/reports/:id` — Update filters/fields
- `POST /api/orgs/:orgId/reports/:id/run` — Execute report, generate export
- `GET /api/orgs/:orgId/reports/:id/schedule` — View scheduled runs

**Report Execution**
- `GET /api/orgs/:orgId/report-runs` — List past runs
- `GET /api/orgs/:orgId/report-runs/:runId/download` — Download export (CSV/PDF/XLSX)

### Documents & E-Signature

**Documents**
- `POST /api/orgs/:orgId/documents` — Upload document
- `GET /api/orgs/:orgId/documents` — List documents (with filters)
- `GET /api/orgs/:orgId/documents/:id` — Document detail + versions
- `GET /api/orgs/:orgId/documents/:id/versions` — Version history

**E-Signature**
- `POST /api/orgs/:orgId/documents/:id/request-signature` — Send signature request
  ```typescript
  {
    recipientEmail: "...",
    recipientName: "...",
    expiresIn: 7 // days
  }
  ```
- `GET /api/orgs/:orgId/signature-requests` — List pending requests
- `PATCH /api/orgs/:orgId/signature-requests/:id/remind` — Send reminder
- `POST /api/webhooks/easysign/signed` — External webhook for signed documents

### Open API & Webhooks

**API Tokens**
- `POST /api/orgs/:orgId/api-tokens` — Generate token
- `GET /api/orgs/:orgId/api-tokens` — List tokens
- `DELETE /api/orgs/:orgId/api-tokens/:id` — Revoke token

**Webhooks**
- `POST /api/orgs/:orgId/webhooks` — Register webhook (lead_created, opportunity_updated, etc.)
- `GET /api/orgs/:orgId/webhooks` — List webhooks
- `DELETE /api/orgs/:orgId/webhooks/:id` — Delete webhook

**Batch Operations (via API)**
- `POST /api/orgs/:orgId/leads/batch` — Create multiple leads
- `POST /api/orgs/:orgId/opportunities/batch` — Create multiple opportunities
- `POST /api/orgs/:orgId/tasks/batch` — Create multiple tasks

### Security & Audit

**MFA**
- `POST /api/users/:id/mfa/setup` — Generate TOTP secret
- `POST /api/users/:id/mfa/verify` — Verify TOTP code
- `POST /api/users/:id/mfa/backup-codes` — Generate backup codes
- `DELETE /api/users/:id/mfa` — Disable MFA

**Audit Log**
- `GET /api/orgs/:orgId/audit-log` — Query audit events (role-based filtering)
- `GET /api/orgs/:orgId/audit-log/export` — Export audit log (CSV/PDF)

**SSO/SAML**
- `POST /api/auth/saml/metadata` — SAML metadata endpoint
- `POST /api/auth/saml/acs` — Assertion Consumer Service (auto-handled by NextAuth)

// public/sw.js
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open('horizon-v1').then((cache) => {
      return cache.addAll([
        '/',
        '/manifest.json',
        '/offline.html',
      ]);
    })
  );
});

self.addEventListener('fetch', (event) => {
  if (event.request.method === 'GET') {
    event.respondWith(
      caches.match(event.request).then((response) => {
        return response || fetch(event.request);
      })
    );
  }
});
